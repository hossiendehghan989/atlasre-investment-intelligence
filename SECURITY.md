# Security Policy

## Supported versions

The `main` branch is actively maintained. AtlasRE is an illustrative, single-user research prototype and is not an authorization system, investment-advice service, or secure repository for sensitive deal data.

## Reporting a vulnerability

Please do **not** disclose security-sensitive details in a public issue. Use GitHub's private vulnerability reporting / Security Advisories for this repository when available. If that option is unavailable, contact the maintainer through [the profile](https://github.com/hossiendehghan989) and include a minimal reproduction, affected component, impact, and suggested mitigation.

Do not include credentials, confidential transaction data, or personal data in a report. Please allow reasonable time for assessment before public disclosure.

## Data boundary

The public demo and committed examples must remain synthetic or illustrative. Never upload owner-supplied deal data, source documents, credentials, or personally identifiable information to this repository or its demo.
