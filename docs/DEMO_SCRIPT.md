# Two-minute demo script — ILLUSTRATIVE case

This walkthrough uses the bundled **ILLUSTRATIVE** case. Do not describe the figures as market evidence, a valuation, or an investment recommendation.

| Time | Click or show | Suggested narration |
| --- | --- | --- |
| 0:00–0:15 | Open the dashboard and leave the default assumptions visible. | “This is a deterministic acquisition screening prototype. The left panel contains the explicit inputs for the illustrative case, and the source status is not verified.” |
| 0:15–0:35 | Point to **What needs attention** and **Downside first**. | “The page starts with gates rather than upside. The default case is `REJECT / REWORK`: source verification is incomplete, unlevered NPV is negative, and levered IRR is below the 12% hurdle. The downside cards show the unlevered NPV, minimum DSCR, expected-shortfall IRR, and chance of value loss.” |
| 0:35–0:50 | Open **Risk tail detail**. | “These are seeded simulation outputs. The seed makes the run reproducible, but the distribution is not calibrated to historical market outcomes.” |
| 0:50–1:05 | Point to **Current case**. | “For these inputs, the model shows 11.97% levered IRR, 9.32% unlevered IRR, a 1.70x equity multiple, and a $12.19 million exit value. The figures update when assumptions change.” |
| 1:05–1:25 | In **Working files**, click **Prepare review files**. | “The dashboard reports progress while it runs the seeded downside simulation and assembles the review package. The result is a ZIP with the memo, assumptions, annual debt schedule, risk summary, illustrative lease references, and Excel workbook.” |
| 1:25–1:45 | Download or open **Excel reconciliation** and show **Reconciliation**. | “The workbook uses live Excel formulas for NOI, monthly debt, IRR, NPV, PMT, IPMT, PPMT, and equity multiple. The adjacent model-output and difference columns let a reviewer identify a mismatch.” |
| 1:45–2:00 | Open **Preview review memo** and end on the control language. | “This does not replace source documents, a complete underwriting workbook, valuation evidence, tax or legal diligence, or committee judgment. The default case remains illustrative and review required.” |

The expected default data points for the demo come from the current code run. If the model version or inputs change, regenerate the screenshots, package, and sample output before using this script.
