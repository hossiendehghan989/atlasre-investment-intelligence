# Code of Conduct

## Our standard

AtlasRE is a technical project for transparent modeling and review. Participants are expected to be respectful, precise, and constructive, especially when discussing assumptions, risk, and model limitations.

Harassment, personal attacks, discrimination, intimidation, doxxing, and deliberately disruptive conduct are not acceptable.

## Enforcement

Report concerns privately through [the maintainer's GitHub profile](https://github.com/hossiendehghan989). Maintainers may edit, close, or remove contributions that violate this standard.
